# SEP-0042 asset list URLs for use with -asset-lists
#
# Verified live: 2026-11-21
# Format: SEP-0042 Stellar Asset List (SAL), https://github.com/stellar/stellar-protocol/blob/master/ecosystem/sep-0042.md
#
# No list is configured by default.  Add one or more of these with -asset-lists
# when running a scan.  Each list is fetched once per scan and attributed
# separately in the report — an outage on one never silences another.
#
# Usage (single list):
#   assay scan -asset-lists https://api.stellar.expert/explorer/public/asset-list/top50 USDC-GA5Z...
#
# Usage (multiple lists):
#   assay scan \
#     -asset-lists https://api.stellar.expert/explorer/public/asset-list/top50 \
#     -asset-lists https://lobstr.co/api/v1/sep/assets/curated.json \
#     USDC-GA5Z...
#
# Comma-separated form also accepted:
#   assay scan -asset-lists https://api.stellar.expert/explorer/public/asset-list/top50,https://lobstr.co/api/v1/sep/assets/curated.json USDC-GA5Z...
